# Amazon RDS Overview
Amazon Relational Database Service (Amazon RDS) is a collection of managed services that makes it simple to set up, operate, and scale databases in the cloud.

## Key Features
- **Managed Service**: Automates administrative tasks like hardware provisioning, database setup, patching, and backups.
- **Engine Types**: MySQL, PostgreSQL, MariaDB, Oracle, SQL Server, and Amazon Aurora.
- **Multi-AZ Deployments**: Provides high availability and failover support for DB instances.
- **Read Replicas**: Allows scaling out beyond the capacity of a single database deployment for read-heavy database workloads.
- **Aurora Serverless v2**: Scales database capacity automatically based on your application's needs.
