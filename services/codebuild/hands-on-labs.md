# AWS CodeBuild - Hands-on Labs

1. **Docker Build and Push**: Create a CodeBuild project that builds a Docker image and pushes it to ECR.
2. **VPC Integration**: Run CodeBuild in a private VPC and query a private RDS instance during tests.
3. **Caching**: Setup S3 and Local caching in `buildspec.yml` to optimize build times.
