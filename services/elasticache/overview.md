# Amazon ElastiCache Overview
Amazon ElastiCache is a fully managed in-memory caching service that supports flexible, real-time use cases.

## Key Features
- **Supported Engines**: Redis and Memcached.
- **Sub-millisecond Latency**: Delivers ultra-fast performance for read-heavy applications.
- **Cluster Mode**: Supports sharding across multiple nodes for scaling write traffic (Redis).
- **Global Datastore**: Fast, reliable, and secure cross-region replication.
- **ElastiCache Serverless**: Automatically scales capacity without managing infrastructure.
