# IAM Architecture Questions

### Q001: What is the best approach for Zero-trust network + IAM architecture?

**Target Services:** IAM

> **Quick Answer:** The best approach for Zero-trust network + IAM architecture is to evaluate requirements and follow least privilege.

#### Detailed Answer
When dealing with Zero-trust network + IAM architecture, ensure that you use IAM features effectively.
