# AWS CodeDeploy - Hands-on Labs

1. **EC2 In-Place Deployment**: Deploy a Node.js app to an EC2 instance using an `appspec.yml`.
2. **ECS Blue/Green Deployment**: Use CodeDeploy to shift traffic 10% at a time between two ECS target groups.
3. **Lambda Traffic Shifting**: Deploy a new version of a Lambda function using linear traffic shifting.
